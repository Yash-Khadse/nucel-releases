# Security

Please report security problems privately, not in a public issue.

- Email **support@nucel.in** with the subject "Security", or use GitHub's private reporting:
  [Report a vulnerability](https://github.com/Yash-Khadse/nucel-releases/security/advisories/new).
- Include what you found, the app version (the APK file name shows it) and steps to reproduce.

This repo only distributes the Android APK. Reports about the app, the web app (app.nucel.in) or the APK's signing are all welcome here.

Only the latest release is supported. A report that the APK does not match its published SHA-256 or signing fingerprint (see the README) is always treated as urgent.
